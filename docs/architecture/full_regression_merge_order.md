# Ordem recomendada de incorporação

Os registros do PASS canônico e o workflow manual de repetição são independentes e alteram arquivos distintos. A incorporação recomendada é:

1. registrar primeiro o resultado validado da regressão integral;
2. incorporar em seguida o workflow manual reutilizável.

A separação mantém distinta a evidência de uma execução já concluída da infraestrutura usada para futuras reexecuções.
